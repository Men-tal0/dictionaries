# 智能词典 (Smart Dictionary)

一个基于 C/C++ 和 Qt 开发的智能词典桌面应用程序，提供轻量级、无广告的本地化词汇查询与管理体验。

##  项目简介
本项目旨在实现一个功能完善、响应迅速的离线词典工具。它结合了 C/C++ 的高效性能与 Qt 的跨平台图形界面优势，并使用轻量级的 SQLite 数据库进行本地词条的存储与管理。用户无需连接互联网即可完成快速查词、释义查看和词库管理。

##  主要功能
- **智能查询**：支持单词的快速检索与精确匹配，即时显示释义。
- **本地词库管理**：基于 SQLite 的本地存储方案，支持词条的增删改查。
- **用户友好界面**：基于 Qt Widgets 构建的直观图形界面，操作流畅。
- **服务端交互（可选）**：内置 `servers` 模块，支持与网络服务的简单数据交互。

## 技术栈
- **编程语言**：C / C++
- **开发框架**：Qt 5.12.9 (Qt Widgets)
- **数据存储**：SQLite 3 (通过 `qlite3.c` / `qlite3.h` 封装)
- **构建工具**：qmake / make
